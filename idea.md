Build a web-based mobile and tablet friendly app for kids to learn about some topic and challenge themselves with questions and answers.

The app must ask few questions before generating study material and set of questions. User will select:
1. grade (k-5) elementry only
2. Subject: Math, science etc
3. Describe in few words what you want to study
4. How many questions you want after the study

Create a kid friendly study material that small kids easily understand and read. Default study material size must be around 3 to 4 pages unless user asks for more in the description

Questions will be multi choice. Kids can select one of multiple choice as an answer. Structure the questions in easy medium hard stage. 50% questions will be each followed by 30% medium and 20% hard

When user enters all the details, the app will use LLM to generate study material that is kid friendly and generate questions in advance. The study material can be paginated with option to move forward and back. At the end of study material, app will ask if you are ready for the test. If user says yes then present questions one at a time to answer will check answer button that says if answer is right or wrong along with explanation. User cannot change answer after checking the answer. User can go back and forth to check their answer or answer an unanswered question. At the end of test, the app must remind user if there is any unanswered question.

The app will keep record of corrects answers and at the end of the test shows the score and also highlight what the kid needs to improve on based on incorrect answers. Make the tests more engaging and fun for kids with plenty of animations
